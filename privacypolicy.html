ZyRo™ Privacy Policy

Last Updated: May 2026

1. Information We Collect

ZyRo™ may collect and store:

  • User IDs
  • Server IDs
  • Channel IDs
  • Message IDs
  • Moderation logs
  • Server settings and configurations

2. Why We Collect Data

The collected data is used only for:

  • Bot functionality
  • Moderation systems
  • Economy and utility features
  • Server customization
  • Improving bot performance

3. Data Sharing

ZyRo™ does not sell, trade, or share user data with third parties.

4. Data Security

We try our best to keep all stored data secure and protected.

5. User Rights

Server owners may request data deletion by contacting the bot developer.

6. Changes

This Privacy Policy may be updated anytime without prior notice.

7. Contact

For support or privacy concerns, contact the ZyRo™ support team.
